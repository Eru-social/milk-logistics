# Молочный Мир: план доставки

Прототип для хакатона. Строит маршруты развоза по Гродно и пересчитывает их при любой правке.

## Как открыть

- Диспетчер: `index.html`
- Водитель: `driver.html` (на телефоне — по QR-коду с кнопки «Водителю»)

Сайт выложен на GitHub Pages. Данные лежат в Supabase (проект `molochny-mir`), поэтому все открытые экраны видят одни и те же заказы, план и отметки водителей.
Если сервер недоступен, диспетчер продолжает работать сам по себе, вместо карты при отсутствии интернета показывается схема.

## Как это работает

1. Логист правит заказы, машины или правила — правка уходит в базу, решатель пересчитывает план, черновик плана сохраняется в базу.
2. Другие экраны получают правку и новый черновик сразу и показывают тот же план.
3. Логист может вручную перенести точку в другую машину и нажимает «Утвердить план».
4. Водитель видит только утверждённый маршрут своей машины и отмечает этапы. Диспетчер видит отметки сразу.

## Что где лежит

| Файл | За что отвечает |
|---|---|
| `index.html` | каркас страницы |
| `css/style.css` | оформление, все цвета заданы переменными в начале файла |
| `driver.html`, `js/driver.js`, `css/driver.css` | страница водителя |
| `js/config.js` | адрес базы Supabase и публичный ключ |
| `js/store.js` | всё общение с базой: загрузка, сохранение, подписка на изменения |
| `js/settings.js` | все правила и допущения в одном месте |
| `js/data.js` | заказы и машины из файла логистов, с координатами |
| `js/solver.js` | решатель маршрутов, написан с нуля |
| `js/map.js` | карта и запасная схема |
| `js/app.js` | экран диспетчера: таблицы, показатели, события |

## Сторонние части и их лицензии

- MapLibre GL JS — отрисовка карты, лицензия BSD-3-Clause.
- OpenFreeMap — бесплатные плитки карты, ключ не нужен.
- Данные карты и координаты адресов — © OpenStreetMap, лицензия ODbL. Подпись на карте обязательна, она стоит в правом нижнем углу.
- Расстояния и время по дорогам между всеми адресами посчитаны один раз открытым сервисом OSRM по данным OpenStreetMap и лежат в базе (таблица `road_matrix`). Решатель считает по ним.
- Линии маршрутов по улицам на карте — открытый демо-сервер OSRM. Годится для прототипа, не для постоянной работы; готовые линии запоминаются в браузере.
- Шрифты Golos Text и Unbounded — Google Fonts, лицензия OFL.
- supabase-js — клиент базы данных, лицензия MIT.
- qrcode-generator — QR-код для страницы водителя, лицензия MIT.

## База данных

Таблицы: `orders`, `vehicles`, `app_settings`, `plans` (черновик и утверждённый план), `driver_events` (отметки водителей), `road_matrix` (расстояния по дорогам, только чтение).
Демо открыто всем, у кого есть ссылка: читать и править можно, удалять нельзя. Кнопка «Сбросить демо» вызывает функцию `reset_demo()`, которая возвращает исходные данные.
