Файлы для работы без интернета

Служебная страница этапа 6 (решение 12). Скачивает с чужих серверов то, что нельзя скачать из облачной сессии Claude, и отдаёт файлами — их нужно положить в проект:

  • supabase.js и supabase-LICENSE.txt — клиент базы supabase-js 2.118.0 (с cdn.jsdelivr.net), точно тот файл, что подключён сейчас: страница сверяет его отпечаток SHA-256;
  • base-roads.js — линии по улицам для эталонного плана и «плана по списку» (с демо-сервера OSRM), чтобы карта рисовала их без интернета.

Нажмите кнопку и подождите около минуты: линии запрашиваются по одной, у бесплатного сервера ограничение на частоту.
